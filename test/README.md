# test

앱과는 상관없는 개발용 도구다. 앱은 이 폴더 없이도 그대로 돌아가고,
GitHub Pages 배포에도 아무 영향이 없다. 지우고 싶으면 `test/`, `package.json`,
`.gitignore`를 지우면 끝이다.

## 왜 있나

앱을 고칠 때마다 손으로 30번 탭하고, 업그레이드 사고, 코인 보내고,
랭킹 탭까지 확인하는 게 CLAUDE.md의 규칙이다. 그건 계속 해야 한다 —
자동 테스트는 **눈으로 보는 것을 대신하지 못한다**. 다만 매번 12개 도시를
전부 눌러볼 수는 없어서, 회귀(예전에 되던 게 조용히 깨지는 것)만 기계에 맡긴다.

브라우저 없이 jsdom으로 진짜 DOM을 띄우고, 실제 `pointerdown`/`click`
이벤트를 쏴서 확인한다. 앱이 세 파일로 나뉘어 있는데 jsdom은 `<link>`와
`<script src>`를 동기로 못 읽어서, 각 테스트 파일 맨 위에서 세 파일을 합쳐
넣는다. 파일 이름을 바꾸면 테스트가 즉시 전부 깨진다.

## 실행

```
npm install     # 처음 한 번 (jsdom 받음)
npm test
```

## 무엇을 보는가

### `core.test.js` — 한 판이 처음부터 끝까지 돌아가는지

도시 선택 → 탭 45회 → 업그레이드 구매 → 코인 송금 → 랭킹. 그리고 재난이 터졌을 때
Support 최상단 고정·3분 카운트다운·효과 2배·빨간 점·만료 후 원상복구.

여기에 **공유 링크의 head**도 본다. OG 태그가 다 있는지, `og:image`가 절대경로이고
`og:url` 밑에 있는지, **`.git/config`의 원격에서 계산한 Pages 주소와 맞는지**
(저장소 이름이 `un_summit`에서 `un-summit`으로 바뀌었을 때 실제로 카드가 깨졌다),
그 태그들이 가리키는 파일이 저장소에 있는지, 매니페스트가 상대경로인지,
그리고 **`DATA_SOURCED`와 게이트 문구가 어긋나지 않는지**.

### `city.test.js` — 규칙이 도시 12곳에서 다 맞는지

**역할** — E/R/B에 따라 탭의 의미, 미터, 업그레이드 사다리가 갈리는 것.
도시 12곳의 업그레이드 이름 60개. My City 한 페이지 통합. 스페이스바 탭.

**하루 보드** — 여섯 도시가 하루를 다 채우면 **전부 정확히 70**. 마지막 30은 밖으로
나간 코인으로만 찬다. 무료 광고 10회 = 만점. 자정에 보드만 0이 되고 누적·업그레이드는
남는 것. 인구를 1000배 해도 점수 불변. B 도시는 양쪽 예산이 절반.

**방벽** — **600탭 + 자기 코인 전부 = 40%로 안전선(50%)에 못 닿는 것**(이게 이 게임의
주장이다). 천장에서 버튼이 사라져 코인·광고가 헛되이 안 쓰이는 것. 매일 10포인트 감쇠.
외부 구호만 천장을 넘는 것.

**해안 도시의 하늘** — 탭으로는 안 걷히고 Tech 송금으로만 걷히는 것. B 도시 송금은
Tech가 아닌 것. 아침에 다시 끼는 것. 배출 도시는 예전 그대로인 것.

**오프라인 수익** — 하루치 절반 천장. 3일 비운 것 = 10시간 비운 것.
**백그라운드 탭이 닫은 탭보다 이득이 아닌 것.** 옛 저장에 지급 0.

**Voice** — 역할에 맞는 질문, 도시 12곳의 선택지 4개, 집계 합이 정확히 100,
의견이 Support·Ranking 어디에도 안 새는 것, 저장한 의견이 다시 보이고 `<script>`가
글자로 남는 것, **초당 갱신이 입력칸의 문장을 안 지우는 것.**

**탭 씹힘** — 같은 버튼을 5번·10번 눌러도 **그 버튼 노드가 그대로 살아 있는지**를
`isConnected`로 본다. 문구가 아니라 노드를 봐야 "안 씹힌다"를 진짜로 검사하는 것이다.
반대로 재생성이 맞는 경우(모드 전환·파도·천장 도달)는 교체되는지를 본다.

**그 밖에** — 장면이 터치 제스처를 삼키는지(폰에서 스크롤됐다), 파도 알림이 네 탭
전부에서 읽히는지, 도시 바꾸기 경고가 잃을 것을 항목으로 세는지,
**Play를 네 번 눌러도 타이머가 두 개뿐인지**(`setInterval`을 세어서 본다).

### `summit.test.js` — 10월 서밋용 다섯 가지

**`?demo=1`** — 울산·서울·부산을 데모로 열고 탭 30번·구매·송금·광고·`flush`·`pagehide`까지
다 한 뒤, **`store.set` 0회, `localStorage` 쓰기 0회, 기존 저장본이 바이트 그대로**인지.
파도는 Support 첫 진입에만 한 번. `?demo=0`/`?demo=10`은 데모가 아닌 것.
**토스트** — 탭 전환에 닫히고 타이머까지 지워지는지, 떠 있는 동안 하단 여백·탭 통과 CSS,
버튼 달린 토스트는 안 닫히고 ×가 있는지. **Voice ↔ Support** — 도시마다 "Voted for" 줄,
내 표를 따라 바뀌는지, 같은 날은 고정, **sample 문구**. **Ranking 진행도** — 탭·송금에
막대가 움직이고 순위표 점수와 같은 값인지, 접힌 설명에 원문이 그대로 있는지.
**Voice 집계** — `VOTES_REAL`과 sample 라벨이 어긋나지 않는지(`DATA_SOURCED`와 같은 방식),
라벨이 막대 바로 위·본문 크기인지, 표 수가 "7 votes (1 yours)"로 맞는지, 다시 눌러 바뀌는지.

도시별 풍경은 그림이라 여기서 못 본다 — 스크린샷으로 확인(HANDOVER 0절).

`city.test.js`에는 규칙을 못 박아둔 검사가 하나 있다. 업그레이드 이름에
`your / household / turn off / recycle / walk` 같은 단어가 들어가면 테스트가
깨진다. **개인 행동이 아니라 도시 인프라만** 다룬다는 원칙을 사람이 잊어도
기계가 기억하게 해둔 것이다.
